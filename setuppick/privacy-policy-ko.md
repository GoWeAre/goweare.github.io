# SetupPick 개인정보처리방침

**그이어(Go We Are)**(이하 "회사")는 **SetupPick**(setuppick.com, 이하 "서비스")을 제공하면서 이용자의 개인정보를 아래와 같이 처리합니다.

**시행일:** 2026-11-01

## 1. 처리하는 정보와 목적

**가. 크리에이터(로그인한 이용자)**

| 항목 | 내용 | 목적 |
|---|---|---|
| Google 계정 정보 | Google이 전달한 이용자 식별값, 이메일 주소, 이름, 프로필 사진 주소 | 로그인, 계정 확인, 서비스 변경 안내 |
| 페이지 정보 | 페이지 주소, 표시 이름, 소개, 프로필 사진, 셋업 사진, 장비 목록과 한 줄 평, 쿠팡 파트너스 링크, 핫스팟 위치, 공개 여부와 공개 시각 | 페이지 만들기와 공개 |
| 채널 인증 정보 | 플랫폼(치지직·유튜브·인스타그램), 채널 식별값, 채널 이름, 채널 주소, 팔로워(구독자) 수, 인증·확인 시각 | 인증 배지와 팔로워 수 표시 |

- 비밀번호는 받지 않습니다. 로그인은 Google 화면에서 이루어집니다.
- 채널 인증은 해당 플랫폼에 로그인해 채널 소유를 확인합니다. 이때 받은 접근 토큰은 확인에만 쓰고 저장하지 않습니다. 팔로워 수는 치지직·유튜브의 경우 공개 정보로 2~3일마다 다시 확인하고, 인스타그램은 다시 인증할 때만 바뀝니다.
- 페이지를 공개하면 표시 이름·소개·프로필 사진·셋업 사진·장비·채널 이름과 배지는 누구나 볼 수 있습니다. 이메일과 Google 식별값은 공개되지 않습니다.

**나. 방문자(로그인하지 않아도 해당)**

| 항목 | 내용 | 목적 |
|---|---|---|
| 방문 기록 | 본 페이지, 접속 IP 주소의 해시, 이전 페이지 주소(최대 500자), 시각 | 크리에이터에게 방문자 수·유입 경로 통계 제공 |
| 클릭 기록 | 누른 장비 또는 광고, 접속 IP 주소의 해시, 이전 페이지 주소, 시각 | 크리에이터에게 클릭 통계 제공, 광고 성과 확인 |

- **IP 주소 원본은 저장하지 않습니다.** 서버 비밀값을 붙여 SHA-256으로 해시한 값만 저장하며, 이 값으로 같은 방문자를 묶어 수를 추정합니다.
- 알려진 검색 로봇, 링크 미리보기, 브라우저의 미리 불러오기는 기록하지 않습니다. 비공개 페이지와 로그인한 상태의 크리에이터 본인 방문·장비 클릭도 기록하지 않습니다.
- 광고 클릭은 어느 페이지에서 눌렀는지와 연결하지 않고 기록하므로, 비공개 미리보기나 본인 클릭도 포함되며 페이지를 삭제해도 90일 보관 기간이 지날 때까지 남습니다.
- 크리에이터에게는 합계와 일별 수, 많이 눌린 장비, 유입 사이트별 수만 보여 주며 IP 해시나 이전 페이지 주소 원문은 보여 주지 않습니다.
- 이름·연락처·위치를 묻지 않으며, 광고 식별자나 외부 분석 도구(Google Analytics, 광고 픽셀 등)를 쓰지 않습니다.

**다. 쿠키**

- 로그인한 크리에이터의 브라우저에 로그인 유지 쿠키를, 로그인과 채널 인증을 진행하는 동안에는 위조 방지를 위한 짧은 쿠키를 둡니다.
- 로그인하지 않고 페이지만 보는 방문자에게 회사가 쿠키를 두지 않습니다.
- 상품 사진은 쿠팡 서버에서 바로 불러오므로, 페이지를 볼 때 브라우저가 쿠팡에 IP 주소와 보고 있는 페이지 주소를 보낼 수 있습니다.
- 장비나 광고를 누르면 쿠팡으로 이동하며, 이때 브라우저가 이전 페이지 주소를 보낼 수 있고 **쿠팡이** 수수료 귀속을 위해 자체 쿠키를 둡니다. 쿠팡의 처리는 쿠팡 개인정보처리방침을 따릅니다. 회사가 따로 쿠팡에 이용자 정보를 보내지는 않습니다.

## 2. 보관 기간과 파기

| 정보 | 보관 기간 |
|---|---|
| 계정·페이지·채널 인증 정보 | 페이지를 삭제할 때까지. 삭제하면 바로 파기합니다 |
| 방문·클릭 기록 | 기록한 날부터 90일. 매일 새벽 90일이 지난 기록을 지웁니다. 페이지를 삭제하면 그 페이지의 기록도 바로 지웁니다 |
| 올린 사진 | 셋업·프로필 사진은 지우거나 바꿀 때, 페이지를 삭제할 때 파기합니다. 직접 등록한 상품 사진은 페이지를 삭제할 때 파기하며, 같은 상품을 다른 크리에이터도 쓰고 있으면 상품 정보로 남습니다 |

- 채널 연결을 해제하면 그 채널 인증 정보는 바로 지웁니다.
- 서버 호스팅 사업자는 운영을 위해 접속 기록을 별도로 처리할 수 있으며, 그 기간은 각 사의 방침을 따릅니다(3항).

## 3. 처리 위탁과 국외 이전

| 받는 곳 | 역할 | 정보 |
|---|---|---|
| Supabase, Inc. (미국) | 데이터베이스, 로그인, 사진 저장(처리 위탁) | 1-가·나의 정보 |
| Cloudflare, Inc. (미국) | 웹 서버와 전송(처리 위탁) | 접속 시 IP 주소 등 통신 정보 |
| Google LLC | Google 로그인, 유튜브 채널 인증(각 사가 자체 방침에 따라 처리) | 로그인·인증 요청과 그 결과 |
| 네이버 주식회사 | 치지직 채널 인증(자체 방침에 따라 처리) | 인증 요청과 그 결과 |
| Meta Platforms, Inc. | 인스타그램 채널 인증(자체 방침에 따라 처리) | 인증 요청과 그 결과 |

- **국외 이전**: 위 Supabase·Cloudflare에 서비스 이용 시점마다 네트워크로 전송됩니다. 저장 위치는 대한민국(Supabase 서울 리전)이며, Cloudflare는 방문자와 가까운 지역의 서버에서 처리합니다. 보관 기간은 2항과 같습니다. 국외 이전을 원하지 않으면 서비스를 쓰지 않거나 페이지를 삭제할 수 있으나, 이 경우 서비스를 이용할 수 없습니다.
- 개인정보처리방침: Supabase <https://supabase.com/privacy>, Cloudflare <https://www.cloudflare.com/privacypolicy/>
- 회사는 위 외에 이용자 정보를 제3자에게 팔거나 제공하지 않습니다.
