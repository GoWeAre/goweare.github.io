**價格與購買。** Agent Office 是一次購買的付費應用程式（美國售價 US$4.99，各國價格以各商店顯示為準）。沒有訂閱、應用程式內購買或廣告。可使用購買時的商店帳號重新安裝。Microsoft Store 與 Steam 為不同的商品，購買其中一方並不包含另一方的使用權。

**購買前請確認。** Steam 提供免費試玩版(1 個工具、1 層樓、累計使用 24 小時)。Microsoft Store 沒有另外提供試用版。請在購買前確認以下事項：

- Windows 10（組建 19041）以上 64 位元版本，以及 Microsoft Edge WebView2 Runtime
- 必須在同一部電腦上使用 Claude Code 或 Codex，才會顯示實際工作
- 介面語言：한국어、English、日本語、繁體中文、Deutsch、Español、Português (Brasil)
- 可透過應用程式內的「體驗畫面」，在不連結任何程式開發工具的情況下瀏覽畫面

**退款。** 付款與退款由您購買的商店處理，並依各商店的退款政策辦理。營運者無法直接退還商店的付款。

- Microsoft Store：請從 Microsoft 帳戶的訂單記錄申請退款。審核與結果依 Microsoft 的政策辦理。
- Steam：請透過 Steam 客服（help.steampowered.com）申請。依 Steam 政策，一般而言在購買後 14 天內且使用時間未滿 2 小時，即可獲得退款。

**遇到問題時。** 如果應用程式無法啟動或沒有顯示工作，無論是否申請退款，都請以電子郵件告訴我們症狀，我們會協助您解決問題。請勿寄送工作階段原始紀錄、API 金鑰或完整路徑。
