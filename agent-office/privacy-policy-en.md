# Agent Office Privacy Policy

**Effective date: 2026-10-31**

---

**Operator:** GoWeAre · **Contact:** go.we.are.official@gmail.com

Agent Office ("the app") runs only on your computer. The operator does not collect, transmit, or sell your personal data through the app.

**What the app reads.** Local Claude Code and Codex session logs you connect (project names, task status, timestamps, request and tool activity, usage) to show them on screen and in notifications. Original logs are never modified and the app does not call any AI model. Files in a session's working folder are read only when you request a preview.

**What is stored on your computer.** Connected folder paths, floor layout, display and notification settings, session nicknames and notes, window links, and office decoration progress are stored in `%LOCALAPPDATA%\AgentOffice`. None of this is sent to the operator.

**Data sharing.** The app contains no analytics, advertising, account server, or log upload. The UI and collector communicate only on this computer (127.0.0.1). Windows, Microsoft Store, Steam, WebView2, Claude Code, and Codex handle data under their own policies.

**Deletion.** For the Microsoft Store version, uninstalling the app also removes its data. For the Steam or ZIP version, fully exit the app and delete `%LOCALAPPDATA%\AgentOffice` to remove the data it created. Original session logs are managed by each coding tool.

**Contact.** Feedback you email us is used only to respond and is deleted on request. Please do not send raw session logs, API keys, or full paths.

**Changes.** If a feature ever requires sending data off your computer, this policy will be updated first and the app will ask for consent.
