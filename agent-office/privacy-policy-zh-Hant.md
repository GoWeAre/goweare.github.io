# Agent Office 隱私權政策

**生效日期：2026-10-31**

---

**營運者：** GoWeAre · **聯絡方式：** go.we.are.official@gmail.com

Agent Office（以下稱「本應用程式」）是僅在使用者電腦上執行的 Windows 應用程式。營運者不會透過本應用程式蒐集、傳送或販售使用者的個人資料。

**本應用程式讀取的資訊。** 讀取使用者所連結的 Claude Code、Codex 本機工作階段紀錄（專案名稱、工作狀態、時間、請求與工具執行紀錄、用量等），並顯示於畫面與通知中。不會修改原始紀錄，本應用程式也不會呼叫任何 AI 模型。僅在使用者要求預覽時，才會讀取該工作階段工作資料夾中的檔案。

**儲存在電腦上的資訊。** 連結資料夾路徑、樓層配置、畫面與通知設定、工作階段別名與備忘、視窗連結、辦公室裝飾進度會儲存在 `%LOCALAPPDATA%\AgentOffice`。這些資訊不會傳送給營運者。

**對外傳送。** 本應用程式沒有分析工具、廣告、帳號伺服器或紀錄上傳功能。畫面與蒐集程式僅在這部電腦內部（127.0.0.1）通訊。Windows、Microsoft Store、Steam、WebView2、Claude Code、Codex 本身的資料處理，依各提供者的政策辦理。

**刪除。** Microsoft Store 版本在解除安裝應用程式時，應用程式資料也會一併刪除。Steam 版與 ZIP 版請在完全結束應用程式後刪除 `%LOCALAPPDATA%\AgentOffice` 資料夾，即可清除本應用程式建立的資料。原始工作階段紀錄由各程式開發工具管理。

**聯絡與意見回饋。** 使用者以電子郵件直接寄送的意見回饋，僅用於回覆詢問，並會依要求刪除。請勿寄送工作階段原始紀錄、API 金鑰或完整路徑。

**變更。** 若新增需要對外傳送資料的功能，我們會先更新本政策，並在應用程式中取得您的同意。
