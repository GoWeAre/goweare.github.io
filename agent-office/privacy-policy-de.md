# Agent Office Datenschutzerklärung

**Gültig ab: 2026-10-31**

---

**Betreiber:** GoWeAre · **Kontakt:** go.we.are.official@gmail.com

Agent Office („die App“) ist eine Windows-App, die ausschließlich auf Ihrem Computer läuft. Der Betreiber erhebt, überträgt oder verkauft über die App keine personenbezogenen Daten von Ihnen.

**Was die App liest.** Die lokalen Sitzungsprotokolle von Claude Code und Codex, die Sie verbinden (Projektnamen, Aufgabenstatus, Zeitstempel, Anfragen und Tool-Aktivitäten, Nutzung), um sie auf dem Bildschirm und in Benachrichtigungen anzuzeigen. Die Originalprotokolle werden nie verändert, und die App ruft kein KI-Modell auf. Dateien im Arbeitsordner einer Sitzung werden nur gelesen, wenn Sie eine Vorschau anfordern.

**Was auf Ihrem Computer gespeichert wird.** Pfade der verbundenen Ordner, Etagenaufteilung, Anzeige- und Benachrichtigungseinstellungen, Spitznamen und Notizen zu Sitzungen, Fensterverknüpfungen und der Fortschritt der Büroeinrichtung werden in `%LOCALAPPDATA%\AgentOffice` gespeichert. Nichts davon wird an den Betreiber gesendet.

**Datenweitergabe.** Die App enthält keine Analysetools, keine Werbung, keinen Kontoserver und keinen Protokoll-Upload. Benutzeroberfläche und Datensammler kommunizieren nur innerhalb dieses Computers (127.0.0.1). Windows, Microsoft Store, Steam, WebView2, Claude Code und Codex verarbeiten Daten nach ihren eigenen Richtlinien.

**Löschung.** Bei der Microsoft-Store-Version werden beim Deinstallieren der App auch ihre Daten entfernt. Bei der Steam- oder ZIP-Version beenden Sie die App vollständig und löschen den Ordner `%LOCALAPPDATA%\AgentOffice`, um die von ihr erstellten Daten zu entfernen. Die Original-Sitzungsprotokolle werden vom jeweiligen Coding-Tool verwaltet.

**Kontakt.** Feedback, das Sie uns per E-Mail senden, wird nur zur Beantwortung verwendet und auf Anfrage gelöscht. Bitte senden Sie keine unbearbeiteten Sitzungsprotokolle, API-Schlüssel oder vollständigen Pfade.

**Änderungen.** Sollte eine Funktion jemals das Senden von Daten von Ihrem Computer erfordern, wird diese Erklärung zuerst aktualisiert, und die App bittet Sie um Ihre Einwilligung.
