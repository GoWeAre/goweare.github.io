# Agent Office 개인정보처리방침

**시행일: 2026-10-31**

---

**운영자:** GoWeAre · **문의:** go.we.are.official@gmail.com

Agent Office(이하 "앱")는 사용자의 컴퓨터에서만 동작하는 Windows 앱입니다. 운영자는 앱을 통해 사용자의 개인정보를 수집·전송·판매하지 않습니다.

**앱이 읽는 정보.** 사용자가 연결한 Claude Code·Codex의 로컬 세션 기록(프로젝트 이름, 작업 상태, 시각, 요청·도구 실행 기록, 사용량 등)을 읽어 화면과 알림에 표시합니다. 원본 기록은 수정하지 않으며, 앱이 AI 모델을 호출하지 않습니다. 사용자가 미리보기를 요청한 경우에만 해당 세션 작업 폴더의 파일을 읽습니다.

**컴퓨터에 저장하는 정보.** 연결 폴더 경로, 층 배치, 화면·알림 설정, 세션 별칭·메모, 창 연결, 사무실 꾸미기 진행 상황을 `%LOCALAPPDATA%\AgentOffice`에 저장합니다. 이 정보는 운영자에게 전송되지 않습니다.

**외부 전송.** 앱에는 분석 도구, 광고, 계정 서버, 로그 업로드 기능이 없습니다. 화면과 수집기는 이 컴퓨터 내부(127.0.0.1)에서만 통신합니다. Windows, Microsoft Store, Steam, WebView2, Claude Code, Codex 자체의 데이터 처리는 각 제공자의 정책을 따릅니다.

**삭제.** Microsoft Store 설치본은 앱을 제거하면 앱 데이터도 함께 삭제됩니다. Steam·ZIP 설치본은 앱을 완전 종료한 뒤 `%LOCALAPPDATA%\AgentOffice` 폴더를 삭제하면 앱이 만든 데이터가 지워집니다. 원본 세션 기록은 각 코딩 도구에서 관리합니다.

**문의와 피드백.** 사용자가 이메일로 직접 보낸 피드백은 문의 응대 목적으로만 사용하며, 요청 시 삭제합니다. 세션 원본·API 키·전체 경로는 보내지 마세요.

**변경.** 외부 전송이 필요한 기능을 추가하는 경우 이 방침을 먼저 갱신하고 앱에서 동의를 받습니다.
