# Política de Privacidade do Agent Office

**Data de vigência: 2026-10-31**

---

**Operador:** GoWeAre · **Contato:** go.we.are.official@gmail.com

O Agent Office ("o app") é um app para Windows que roda somente no seu computador. O operador não coleta, transmite nem vende seus dados pessoais por meio do app.

**O que o app lê.** Os registros de sessão locais do Claude Code e do Codex que você conectar (nomes de projeto, status das tarefas, horários, atividade de solicitações e ferramentas, uso) para exibi-los na tela e em notificações. Os registros originais nunca são modificados e o app não chama nenhum modelo de IA. Os arquivos da pasta de trabalho de uma sessão só são lidos quando você solicita uma pré-visualização.

**O que fica armazenado no seu computador.** Caminhos das pastas conectadas, layout dos andares, configurações de tela e de notificações, apelidos e anotações das sessões, vínculos de janelas e o progresso da decoração do escritório são armazenados em `%LOCALAPPDATA%\AgentOffice`. Nada disso é enviado ao operador.

**Compartilhamento de dados.** O app não contém ferramentas de análise, anúncios, servidor de contas nem envio de registros. A interface e o coletor se comunicam somente dentro deste computador (127.0.0.1). Windows, Microsoft Store, Steam, WebView2, Claude Code e Codex tratam dados de acordo com suas próprias políticas.

**Exclusão.** Na versão da Microsoft Store, desinstalar o app também remove os dados dele. Na versão Steam ou ZIP, feche o app completamente e exclua a pasta `%LOCALAPPDATA%\AgentOffice` para remover os dados criados por ele. Os registros de sessão originais são gerenciados por cada ferramenta de programação.

**Contato.** O feedback que você nos enviar por e-mail é usado apenas para responder e é excluído mediante solicitação. Não envie registros de sessão brutos, chaves de API nem caminhos completos.

**Alterações.** Se algum recurso vier a exigir o envio de dados para fora do seu computador, esta política será atualizada antes e o app pedirá seu consentimento.
