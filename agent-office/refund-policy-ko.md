# Agent Office 구매·환불 안내

**시행일: 2026-10-31**

---

**운영자:** GoWeAre · **문의:** go.we.are.official@gmail.com

**가격과 구매.** Agent Office는 한 번 구매하는 유료 앱입니다(미국 기준 US$4.99, 국가별 가격은 각 스토어에 표시). 구독·앱 내 결제·광고가 없습니다. 구매한 스토어의 계정으로 다시 설치할 수 있습니다. Microsoft Store와 Steam은 별도 상품이며 한쪽 구매가 다른 쪽 이용 권한을 포함하지 않습니다.

**구매 전 확인.** 별도 체험판은 없습니다. 대신 구매 전에 다음을 확인해 주세요.

- Windows 10(빌드 19041) 이상 64비트, Microsoft Edge WebView2 Runtime
- 같은 컴퓨터에서 Claude Code 또는 Codex를 사용하고 있어야 실제 작업이 표시됩니다
- 화면 언어: 한국어, English, 日本語, 繁體中文, Deutsch, Español, Português (Brasil)
- 앱 안의 "체험 화면 보기"로 코딩 도구 연결 없이 화면을 둘러볼 수 있습니다

**환불.** 결제와 환불은 구매한 스토어가 처리하며 각 스토어의 환불 정책을 따릅니다. 운영자는 스토어 결제를 직접 환불할 수 없습니다.

- Microsoft Store: Microsoft 계정의 주문 기록에서 환불을 요청합니다. 심사와 결과는 Microsoft 정책을 따릅니다.
- Steam: Steam 고객 지원(help.steampowered.com)에서 요청합니다. Steam 정책상 일반적으로 구매 후 14일 이내, 사용 시간 2시간 미만이면 환불을 받을 수 있습니다.

**문제가 있을 때.** 앱이 실행되지 않거나 작업이 표시되지 않으면 환불 요청 전후와 관계없이 이메일로 증상을 알려 주세요. 문제 해결을 돕습니다. 세션 원본·API 키·전체 경로는 보내지 마세요.

**업데이트.** 오류 수정과 호환성 업데이트를 추가 비용 없이 제공하기 위해 노력합니다. 특정 기간의 업데이트나 향후 기능 추가를 보장하지는 않습니다.

이 안내는 거주 국가의 법률이 보장하는 소비자 권리를 제한하지 않습니다.
